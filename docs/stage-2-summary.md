# Stage 2 — Self-hosted Agent & CI/CD Hardening

**Status:** Completed — assessment and validation
**Project:** Azure Landing Zone POC

## Objective

Assess the security and reliability of the self-hosted Azure DevOps agent and its CI/CD deployment workflow.

## Summary of Work

- Reviewed agent security and operational configuration.
- Assessed CI/CD workflow controls and deployment approval behavior.
- Validated the deployment approval rejection path.
- Documented remaining hardening opportunities for follow-up.

## Validation Outcome

The approval-rejection test confirmed that the deployment workflow was blocked when approval was rejected.

## Follow-up Improvements

Further hardening and access-control reviews remain tracked as follow-up improvements. Completion of the Stage 2 assessment does not imply that every security improvement has been implemented or independently verified.
